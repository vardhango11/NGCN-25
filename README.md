# NGCN-25
## Folder Structure

```

NGCN-25/
│
├── frontend/     # React frontend application
└── backend/      # Backend (currently empty / placeholder)

````

---
## Frontend (React)

The frontend is built using **React**.

### Prerequisites
- Node.js (v18+ recommended)
- npm

### How to start the frontend

```bash
cd frontend
npm install
npm start
````

The application will run at:

```
http://localhost:3000
```
